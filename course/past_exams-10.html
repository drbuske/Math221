    Exercises Questions

    1.

    The length of a rectangle is increasing at a rate of 8 cm/sec and its width is increasing at a rate of 3 cm/sec. When the length is 20 cm and the width is 10 cm, how fast is the area of the rectangle increasing?
    🔗
    Answer.
    Let \(A(t)=L(t)W(t)\text{.}\) Then
    \begin{equation*} \frac{dA}{dt} = L\frac{dW}{dt} + W\frac{dL}{dt}. \end{equation*}
    Substituting the given values,
    \begin{equation*} \frac{dA}{dt} = 20(3)+10(8) = 140. \end{equation*}
    The area is increasing at \(140~\text{cm}^2/\text{sec}\text{.}\)
    🔗
    🔗
    🔗

    2.

    Suppose the derivative of a function \(f\) is given by
    🔗
    \begin{equation*} f'(x)=(x-2)^2(x+4). \end{equation*}
    1. Use a first-derivative sign chart to determine the intervals on which \(f\) is increasing.
      🔗
      🔗
    2. Does \(f\) have any local maxima? If so, where?
      🔗
      🔗
    3. Does \(f\) have any local minima? If so, where?
      🔗
      🔗
    Answer.
    The critical numbers are \(x=-4\) and \(x=2\text{.}\)
    🔗
    Since \((x-2)^2 \ge 0\text{,}\) the sign of \(f'(x)\) is determined by \(x+4\text{.}\)
    🔗
    Therefore:
    🔗
    • \(f'(x) < 0\) on \((-\infty,-4)\text{.}\)
      🔗
    • \(f'(x) > 0\) on \((-4,2)\text{.}\)
      🔗
    • \(f'(x) > 0\) on \((2,\infty)\text{.}\)
      🔗
    Hence \(f\) is increasing on \((-4,2)\cup(2,\infty).\)
    🔗
    There is no local maximum because the derivative never changes from positive to negative.
    🔗
    There is a local minimum at \(x=-4\text{.}\)
    🔗
    🔗
    🔗

    3.

    Consider the function \(f(x)=\frac{\ln x}{x}.\)
    🔗
    1. State the domain of \(f\text{.}\)
      🔗
      🔗
    2. Evaluate \(\displaystyle\lim_{x\to0^+}\frac{\ln x}{x}\text{.}\) Defend your response.
      🔗
      🔗
    3. Determine the maximum value attained by \(f\) and where it occurs. Again, defend your response.
      🔗
      🔗
    4. \(f\) has a point of inflection at \(x=e^p\) where \(p=\underline{\hspace{10mm}}\text{.}\)
      🔗
      🔗
    Answer.
    1. Domain: \((0,\infty).\)
      🔗
      🔗
    2. \begin{equation*} \lim_{x\to0^+}\frac{\ln x}{x} = -\infty. \end{equation*}
      🔗
    3. Differentiate:
      🔗
      \begin{equation*} f'(x) = \frac{1-\ln x}{x^2}. \end{equation*}
      Critical number:
      🔗
      \begin{equation*} 1-\ln x=0 \implies x=e. \end{equation*}
      Since \(f'\) changes from positive to negative at \(x=e\text{,}\) \(f\) attains an absolute maximum there.
      🔗
      \begin{equation*} f(e) = \frac{1}{e}. \end{equation*}
      🔗
    4. Differentiate again:
      🔗
      \begin{equation*} f''(x) = \frac{-3+2\ln x}{x^3}. \end{equation*}
      Setting the numerator equal to zero gives
      🔗
      \begin{equation*} -3+2\ln x=0. \end{equation*}
      \begin{equation*} \ln x=\frac32. \end{equation*}
      \begin{equation*} x=e^{3/2}. \end{equation*}
      🔗
    🔗
    🔗

    4.

    A car traveling along a straight road is braking and its velocity is measured at several different points in time, as recorded in the table.
    🔗
    \(t\) 0 0.4 0.8 1.5 2.0
    \(v(t)\) 100 88 72 54 0
    1. Estimate the total distance traveled during the time the car brakes using a right Riemann sum \(R_4\) with 4 subintervals.
      🔗
      🔗
    2. Assuming that \(v(t)\) is always decreasing on \([0,2]\text{,}\) what is the maximum possible distance the car traveled before it stopped? Why?
      🔗
      🔗
    Answer.
    1. \(R_4 = (0.4)(88)+(0.4)(72)+(0.7)(54)+(0.5)(0) = 101.8.\)
      Approximate distance: \(101.8\) feet.
      🔗
      🔗
    2. \(L_4 = (0.4)(100) +(0.4)(88) +(0.7)(72) +(0.5)(54) = 152.6.\)
      Maximum possible distance: \(152.6\) feet.
      🔗
      🔗
    🔗
    🔗

    5.

    Calculate the value of each limit below or state that it does not exist. Be sure to defend your answers.
    🔗
    1. \(\displaystyle \displaystyle \lim_{t\to1} \frac{nt^n-(n+1)t^{n-1}+1}{2(t-1)}.\)
      🔗
    2. \(\displaystyle \displaystyle \lim_{x\to{-\frac{\pi}{2}^+}} \frac{x+\frac{\pi}{2}}{\tan(x)}.\)
      🔗
    Answer.
    1. Since both the numerator and denominator approach 0, we apply L’Hôpital’s Rule:
      \begin{align*} \lim_{t\to1} \frac{nt^n-(n+1)t^{n-1}+1}{2(t-1)} \mathstrut \amp = \lim_{t\to1} \frac{n^2t^{n-1} - (n-1)(n+1)t^{n-2}}{2} \\ \amp = \frac{n^2 - (n^2-1)}{2} \\ \amp =\frac{1}{2}. \end{align*}
      🔗
      🔗
    2. L’Hôpital’s Rule is not applicable since the numerator gets close to 0 while the denominator gets close to \(-\infty\text{.}\) The limit is simply approaching 0.
      🔗
      🔗
    🔗
    🔗

    6.

    Calculate the left Riemann sum \(\displaystyle \sum_{k=1}^{3} f(x_k)\Delta x\) on the interval \([1,7]\) where \(\Delta x=2\text{.}\) The graph of \(f\) passes through \((1,2)\text{,}\) \((3,5)\text{,}\) \((5,7)\text{,}\) and \((7,8)\text{.}\)
    🔗
    Answer.
    \(L_3 = 2(2)+2(5)+2(7) = 28.\)
    🔗
    🔗

    7.

    Evaluate each expression.
    🔗
    1. \(\displaystyle \displaystyle \sum_{k=3}^{10}4\)
      🔗
    2. \(\displaystyle \displaystyle \sum_{m=1}^{200}m^3 - \sum_{m=1}^{199}m^3\)
      🔗
    3. \(\displaystyle \displaystyle \sum_{k=1}^{4}(-1)^k k^k\)
      🔗
    Answer.
    1. \begin{equation*} (4+4+4+\ldots+4)_{\underbrace{\text{8 times}}}=8(4)=32. \end{equation*}
      🔗
    2. \begin{equation*} \sum_{m=1}^{200}5m^3 = 200^3 = 8,000,000. \end{equation*}
      🔗
    3. \begin{equation*} (-1)^1\cdot 1^1 + (-1)^2\cdot 2^2 + (-1)^3\cdot 3^3 + (-1)^4\cdot 4^4 = -1 + 4 -27+256 = 232 \end{equation*}
      🔗
    🔗

    8.

    Consider all rectangles (two examples appear here) which have two sides on the positive coordinate axes and which lie under the curve \(y=2\cos(x)\text{.}\) The one with the largest perimeter has width \(\underline{\hspace{10mm}}\) and height \(\underline{\hspace{10mm}}\text{.}\)
    🔗
    Answer.
    Define the perimeter in terms of \(x\) which is the length of the base of the rectangle by
    \begin{equation*} P(x)=2x+4\cos(x). \end{equation*}
    Then,
    \begin{equation*} P'(x)=2-4\sin(x) = 0 \end{equation*}
    exactly when \(\sin(x) = \frac{1}{2}\text{.}\) This first happens for positive \(x\)-values when \(x=\frac{\pi}{6}\) radians. A first-derivative sign chart shows that
    \begin{equation*} P'(x) > 0 \text{ for } 0 < x < \frac{\pi}{6} \end{equation*}
    and
    \begin{equation*} P'(x) < 0 \text{ for } \frac{\pi}{6} < x < \frac{\pi}{2}. \end{equation*}
    The following table shows that the maximum perimeter occurs when \(x=\frac{\pi}{6}\) which occurs when the height is \(2\cos(\frac{\pi}{6}) = 2\cdot \frac{\sqrt{3}}{2} = \sqrt{3}.\)
    🔗
    \(x\) \(P(x)\)
    \(0\) \(4\)
    \(\frac{\pi}{6}\) \(2\frac{\pi}{6} + 4\frac{\sqrt{3}}{2} \approx 4.51\)
    \(\frac{\pi}{2}\) \(2\frac{\pi}{2} + 4\cos(\frac{\pi}{2}) = \pi\)
    🔗
    🔗

    9.

    The maximum value of \(f(x)=\sqrt{x} + \frac{4}{x}\) on \(\left[ \frac{1}{4}, 100 \right]\) occurs at \(x= \underline{\hspace{10mm}}.\) The maximum value of \(f\) attained on this interval is \(\underline{\hspace{10mm}}\text{.}\)
    Answer.
    \begin{equation*} f'(x)= \frac{1}{2}x^{-\frac{1}{2}} - 4x^{-2} = 0 \end{equation*}
    \begin{equation*} \iff \frac{1}{2}x^{\frac{3}{2}} - 4 = 0 \end{equation*}
    \begin{equation*} \iff x^{\frac{3}{2}} = 8 \end{equation*}
    \begin{equation*} \iff x^{\frac{1}{2}} = 2 \end{equation*}
    \begin{equation*} \iff x = 4. \end{equation*}
    Setting up a table and checking endpoints and critical numbers tells us that the maximum value occurs at \(x=\frac{1}{4}\) and the maximum value of \(f\) attained on the interval is 16.5.
    🔗
    \(x\) \(f(x)\)
    \(\frac{1}{4}\) \(\frac{1}{2} + 16 = 16.5\)
    \(4\) \(2+1=3\)
    \(100\) \(10+0.04 = 10.04\)
